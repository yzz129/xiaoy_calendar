# 小Y日历微信小程序

这是现有微信小程序 AppID 的“小Y日历”原生工程，不使用 `web-view`。原因是该 AppID 为个人主体，个人主体不能发布包含 `web-view` 的小程序。

## 已替换内容

- AppID：`wxfb514417ee21e094`
- 项目名称与页面名称：小Y日历
- 图标：`assets/app-icon.png`
- 网页端同款宠物素材：`assets/pet/`，包含待命、专注、思考、庆祝、休息五种形态
- 网页端同款字体：通过 `https://calendar.yzzwnw.asia/fonts/` 先加载小程序常用字形，再在后台补齐全量字体，减少首屏等待
- API 域名：`https://calendar.yzzwnw.asia`
- 代码：原生小程序登录、注册、月历、日期底部抽屉、每日状态、工期、便签、规划、Agent、管理员后台、云端同步、账号与隐私页面
- 原工程的名称、域名和页面代码均已移除

## 当前功能

- 与网页端、PWA 和 Android 共用账号及云端数据；日历、工期、便签和规划可跨端同步。
- 管理员账号登录后可进入原生管理员后台，查看用户、使用情况、聊天记录、AI 调用和用户行为。
- 小Y 宠物会根据待命、聊天输入、AI 思考、规划完成、拖动和夜间时段自动切换形态。
- 宠物支持自由拖动、贴边隐藏、隐藏状态拖动和再次唤回；聊天框使用气泡布局并可自由调整尺寸。
- 月历、日期详情、规划、个人资料和后台页面均针对手机安全区及窄屏边界进行适配。

当前开发版本：`2.1.9`。

### 隐私与内容声明

- 《小程序用户隐私保护指引》应与代码一致：处理用户自行填写的昵称、账号凭据、日历状态、工期、便签、规划，以及必要的 IP、设备类型、访问时间和由 IP 粗略推断的网络出口城市信息；该城市不是手机 GPS 定位。
- 当前小程序不申请精确位置、通讯录、相册、相机、麦克风或微信头像昵称权限。
- 用户生成内容场景说明填写：`用户仅创建本人可见的私人日历、便签和规划，不提供用户内容的公开发布、分享、评论、社区或其他用户访问功能。小程序入口转发不包含用户日历数据。`
- 小程序订单中心 path 不涉及交易，无需设置。

个人主体不需要、也无法为本工程配置 `web-view` 业务域名。

## 导入与检查

在微信开发者工具中选择“导入项目”，目录选择本文件夹。代码上传前在仓库根目录运行：

```bash
npm run validate:miniprogram
```

开发者工具本地调试已在私有配置中关闭域名校验；真机预览和提交审核前必须完成 request 与 downloadFile 合法域名配置。
