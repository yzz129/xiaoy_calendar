隐私政策

更新日期：2026年8月20日

小Y日历需要使用昵称和密码登录。日历仍会保存在当前设备，并在登录后加密传输至 Cloudflare，用于跨会话恢复；Agent 对话、模型调用与必要的使用记录会按账号保存。

一、信息的收集与使用

首次使用需要填写昵称和密码注册账号，注册成功后会自动登录。我们保存昵称及不可逆的密码哈希，不保存明文密码；同时记录注册/登录时间、最近活动时间、用于安全审计的 IP 与设备浏览器信息。我们不要求姓名、手机号、身份证号、位置、通讯录、相册或广告标识。请不要在便签、规划或 Agent 对话中输入证件号码、银行卡号等敏感信息。

二、本地数据与云端同步

登录后，工作状态、工期、便签、学习/工作规划和每日任务调整以 Cloudflare D1 中的账号快照为主，并在多个设备之间同步。当前设备会保留一份离线缓存，断网时仍可继续使用，恢复联网后自动同步最新变更。退出登录不会自动删除离线缓存；卸载应用或清除浏览器数据会删除该设备缓存。

三、权限与第三方服务

  • 应用不接入广告、第三方统计或推送服务；账号登录与同步由小Y日历自己的 Cloudflare 服务处理。
  • 应用不主动申请相机、麦克风、定位、通讯录或相册权限。
  • 基础日历功能可在缓存完成后离线使用；小Y Agent 与联网搜索需要网络连接。
  • Agent 请求由 Cloudflare Pages Functions 处理，并可能转发至 OpenRouter、Pollinations 或 Agnes 生成回答；需要查询时会调用 Tavily 搜索。实际处理受相应服务的隐私政策约束。
  • 应用不会把服务密钥写入网页或保存在用户设备中；密钥以 Cloudflare 加密 Secret 形式保管。

四、数据共享与转让

我们不会出售或转让你的信息。仅在你主动使用 Agent 时，为完成回答而向上述模型或搜索服务提供消息、规划偏好、已有规划摘要和未来 42 天内的状态/任务摘要；便签正文不会作为日历摘要发送。为提供历史查询、安全排障和用量审计，服务端会保存 Agent 对话、模型名称、请求/响应摘要、调用状态与耗时。

五、管理、保存与删除

授权管理员可在后台查看并管理账号，以及查看该账号的日历快照、规划、Agent 聊天、模型调用和带时间的使用记录。上述访问仅用于账号管理、服务运营与安全排障。用户可通过下方邮箱申请查询、更正或删除账号及云端数据；管理员删除账号时，其会话、同步快照、聊天、调用和活动记录会一并删除。

六、未成年人保护

小Y日历不设置面向未成年人的账号、社交、支付或内容服务，也不会主动收集未成年人的个人信息。

七、政策更新与联系

如本政策发生变化，更新后的内容会发布在本页面。如有疑问，可联系开发者 yzz，联系邮箱：2104419029@qq.com。
